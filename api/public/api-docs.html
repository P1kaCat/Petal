Build something that blooms.

Discover Minecraft content, publish author releases and connect your tools to Petal.

Download OpenAPI 3.1

Start with public discovery

Search and approved downloads are available without an account. Use official version identifiers when filtering Minecraft compatibility.

GET /v1/search?q=sodium&loader=fabric&limit=20
GET /v1/projects/{projectId}/versions?version=1.21.1&loader=fabric
GET /v1/versions/{versionId}/download

Connect an author account

Create a scoped token from your account page. Select only the permissions your integration needs. Tokens expire within 90 days and can be revoked immediately.

Authorization: Bearer ptl_YOUR_PRIVATE_TOKEN
Content-Type: application/json

Project writes still require ownership or accepted maintainer access. Distribution declarations, compatibility checks and moderation apply to every client.

Read the next page

Content collections return items, limit and nextCursor. Pass the cursor on the next request. Each page has at most 100 records. Public search keeps its existing offset format.

Understand a failed request

Errors return safe problem details and a server-generated request identifier. The error field remains available to older clients.

{ "status": 403, "code": "permission_denied",
  "detail": "API token scope does not permit this action.",
  "requestId": "…" }
